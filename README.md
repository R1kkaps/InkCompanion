# 墨伴 / Ink Companion

给 NRF_EPD_71E9（ZKC42VM 4.2 寸）做的 Windows 原生桌面应用。
图像处理、预览和音乐封面排版都在本地完成；蓝牙直接连接 Windows，无需打开网页。
**当前为 1.5 Apple 风格界面升级版。** 使用 Windows 系统字体、macOS 式分组卡片、分段标签和克制的即时按压反馈；黑白传图、修正后的红色平面及三色抖动均已实机验收。
按 Service UUID 捕获广播，使用当前 BLEDevice 和实际地址类型连接，不依赖名称或固定 MAC。连接后读取原驱动配置，并向官网提交 SID 做兼容性校验；SID 不写入日志。

## 打开

双击 `start.cmd`；新发布版程序是 `dist/InkCompanion-1.5/InkCompanion-1.5.exe`。
解压新包后可直接打开同名 EXE。请保留整个文件夹，不能只复制 EXE。

1. 唤醒墨水屏蓝牙，断开 epdiy 网页或其他手机的连接。
2. 点“连接墨水屏”；累计监听最多 180 秒，连接重试另计。等待期间可以停止。
3. 显示“屏幕已就绪”后，选择图片并调整预览，再点发送。
4. 幻灯片与歌曲封面可选择自动发送；默认关闭。
5. 点“停止 / 断开”取消当前操作。详细 GATT 信息可展开查看。

连接通路：无名称过滤的 ACTIVE callback → 最大容量 1 的 asyncio.Queue → 停止扫描 →
当次 BLEDevice + 广播实际 Random/Public 类型 → BleakClient → 全部服务枚举 → 只读固件版本。
失败后清理连接，重新等待新广播再重试；不保存固定 MAC 作为连接依据。

如果网易云未出现在媒体来源中，检查播放器是否启用了 Windows 系统媒体控件 / SMTC。
不同版本的设置入口可能不同；只有播放器提供了媒体会话和封面，应用才能直接读取。
可以在下拉框中手动选择具体的媒体来源；“Windows 当前媒体会话”也可能选中浏览器视频。
封面暂未提供时显示明确状态及占位图，不会伪造封面。

## 功能

- 黑白反转、0/90/180/270 度旋转、左右镜像、上下翻转。
- 针对当前倒装屏幕默认选择 180°；主图和边栏作为完整画面一起旋转，应用预览和实际发送像素使用同一方向。边栏位置按实体安装后的方向选择。升级时会将旧版方向设置迁移一次，此后继续记住手动选择。
- 三色（黑白红）输出：采用网页同款黑/白/红调色板量化，提供 Floyd–Steinberg、Jarvis、Stucki、Burkes、Sierra、Atkinson、Bayer 算法和强度调整。
- 自由缩放 / 平移裁切：缩放倍数、水平/垂直位置；预览滚轮缩放、左键拖拽定位、双击重置。
- 完整留白、填满裁剪、拉伸；亮度、对比度、黑白阈值、Floyd–Steinberg 照片抖动。
- 400×300 精确发送预览及 PNG 导出。
- 可选信息边栏：右、左、上、下四个位置，厚度限制为 34–48 px，新版默认 48 px。日期、星期、温度、天气和电压均使用更大的高对比字号。边栏会为主图预留空间，不会覆盖原图。
- 边栏显示日期、当前天气、温度和墨水屏实测电压；城市可编辑。天气每 30 分钟更新并写入本地缓存，断网时保留最近一次结果。
- 天气图标区分昼夜：晴天太阳/月亮、少云太阳云/月亮云，并提供云、雨、雪、雷、雾图形。图标参考 Lucide 的 24 px 轮廓关系，重画为适合一位黑白墨水屏的粗线和实心形状。
- 边栏没有信息的剩余区域使用确定性黑白点阵渐隐；不使用灰色像素，预览与最终一位发送数据一致。
- 可选择让边栏在日期、天气或电量变化后按最短刷新间隔自动发送；默认关闭自动发送。
- 预览计算在后台执行；90ms 内连续发生的滚轮、拖动和参数变化会合并，只生成最新画面，发送与保存会等待最终预览完成。
- 本地幻灯片和歌曲封面预览更新；封面可单独显示或加歌名/歌手。
- GATT 连接、取消、逐 characteristic 信息、完整异常/HRESULT/重试记录。
- 保存图像参数和幻灯片列表；自动发送和音乐监听默认关闭。

## 实机范围

已实机读取固件 v1.10-om6626、驱动 0x16（三色）、244 字节分包、RLE、64 个槽位。
已实机完成向空槽位 1 传图并提交刷新，固件确认槽位写入；原槽位 0 保留。用户确认三色测试图显示完整，方向及黑白红逻辑正确。
三色屏发送黑白+红色双平面。官网协议的红平面为低电平有效：`0=红色`、`1=非红色`；未启用红色时发全 `0xFF` 清除旧红色。预览先完成三色量化，再由同一张预览生成两个平面，保证黑、白、红互斥。

槽位策略：优先使用空槽位，保留连接前已存储的图片。同一次连接里，相同图像直接切换缓存槽位；槽位满时只复用本次连接写入成功的槽位。断开后不再宣称拥有这些槽位。若设备已满且没有本次会话槽位，则停止写入。跨会话槽位管理尚未实现，长期使用会占用空槽位。
独立 `ble_connection.py` 仍是完全只读诊断工具，不含 write/start_notify/pair 操作。

“实时”是每 2 秒检测封面变化，再按屏幕传输和刷新能力发送。
默认每次提交刷新后至少等待 15 秒，可调；不能将全刷墨水屏变成高帧率视频屏。
蓝牙完成不等于物理刷新完成，实际显示、残影、方向及最短间隔需实机观察。

## 开发

Python 3.13 x64，PySide6、Pillow、Bleak、PyWinRT。

```powershell
.\setup.ps1 -Python 'C:\path\to\python.exe'
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest -v test_connection test_core test_prepare test_weather
.\.venv\Scripts\python.exe ble_connection.py --seconds 180 --attempts 5
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\build.ps1 -Name 'InkCompanion-1.5'
```

本机开发环境已经放在项目 `.venv`，可以直接运行。
图像处理在 `imaging.py`，分包在 `protocol.py`，蓝牙/媒体在 `backend.py`，界面在 `app.py`。
协议依据、边界及命令格式见 `PROTOCOL.md`。

设置和滚动日志：%LOCALAPPDATA%\InkCompanion；桌面 GATT 记录在其 ble 子目录。
命令行日志默认在 research/ble，包括 JSONL、完整 Bleak 客户端调试日志和成功后的 GATT JSON。
异常包含 traceback、异常链、winerror/hresult（存在时）以及十六进制代码。
probe.py 已替换为同一个只读连接工具的入口，不再执行初始化或官网校验。
